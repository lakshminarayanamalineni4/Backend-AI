# Week 1 Overview

Week 1 is the auth and foundation sprint for the Cashback & Rewards Processing Platform 2.0. The goal is to establish the backend shell, the local development workflow, and the first Angular screens so later backend modules can be added on top of a stable base.

## Week 1 goals

- Define the repository structure and local environment.
- Build the FastAPI app entry point and health check.
- Start the Angular app with routing and basic layout.
- Learn the core Docker concepts needed for local development.

## What should be done by the end of the week

- [ ] Backend app runs locally with a `/health` endpoint.
- [ ] Angular app starts with placeholder routes for auth and dashboard.
- [ ] Environment variables are documented in `.env.example`.
- [ ] Docker basics are understood well enough to use Compose in Week 2.
