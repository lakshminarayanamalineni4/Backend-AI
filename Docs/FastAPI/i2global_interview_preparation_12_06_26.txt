
# 3. Pydantic Models

```python
from pydantic import BaseModel, EmailStr

class UserCreate(BaseModel):
    name: str
    email: EmailStr
    age: int
```

Purpose:

* Request validation
* Type checking
* Schema generation

Benefits:

* No manual validation
* Automatic error responses

---

# 4. Request Body

```python
@app.post("/users")
def create_user(user: UserCreate):
    return user
```

Request:

```json
{
    "name":"Lakshmi",
    "email":"abc@gmail.com",
    "age":25
}
```

Used for:

* Create APIs
* Update APIs
* Login APIs

# 5. Query Parameters


# 7. Dependency Injection

```python
from fastapi import Depends

def get_db():
    db = SessionLocal()

    try:
        yield db

    finally:
        db.close()
```

Usage:

```python
@app.get("/users")
def get_users(
    db=Depends(get_db)
):
    pass
```

Purpose:

* Reusability
* Cleaner code
* Testability

Common Uses:

* Database sessions
* Authentication
* Configurations

---

# 8. Database Connection

```python
from sqlalchemy import create_engine
from sqlalchemy.orm import sessionmaker

DATABASE_URL = "postgresql://user:password@localhost/db"

engine = create_engine(DATABASE_URL)

SessionLocal = sessionmaker(
    autocommit=False,
    autoflush=False,
    bind=engine
)
```

Flow:

```
Engine
↓
SessionLocal
↓
get_db()
↓
API
```

# 9. SQLAlchemy Queries

Fetch All:

```python
db.query(User).all()
```

Equivalent SQL:

```sql
SELECT * FROM users;
```

Fetch One:

```python
db.query(User).filter(
    User.email == email
).first()
```

Equivalent SQL:

```sql
SELECT * FROM users
WHERE email = ?
LIMIT 1;
```

Insert:

```python
db.add(user)
db.commit()
```

Update:

```python
db.commit()
```

Delete:

```python
db.delete(user)
db.commit()
```

# 10. JWT Authentication

Login Flow:

```
Email + Password
↓
Validate Request
↓
Fetch User
↓
Verify Password
↓
Generate JWT
↓
Return Token
```

JWT Payload:

```python
{
    "user_id":1,
    "role":"admin"
}
```

Protected Route:

```python
current_user = Depends(
    get_current_user
)
```

Authorization Header:

```
Bearer eyJhbGc...
```

JWT = Stateless Authentication

# 11. Password Hashing

Hash Password:

```python
bcrypt.hashpw(
    password.encode(),
    bcrypt.gensalt()
)
```

Verify Password:

```python
bcrypt.checkpw(
    entered_password.encode(),
    stored_password
)
```

Important:

* Passwords are hashed
* Not encrypted

# 13. Async vs Sync

Sync:

```python
def get_users():
```

Async:

```python
async def get_users():
```

Use Async For:

* API calls
* Database calls
* File operations
* Network operations

Avoid Async For:

* Heavy CPU calculations
* Image processing
* Video processing

Interview Answer:

Async allows the application to handle other requests while waiting for I/O operations to complete.

---

# 14. Middleware

```python
@app.middleware("http")
async def middleware(
    request,
    call_next
):
    response = await call_next(request)
    return response
```

Runs before and after every request.

Uses:

* Logging
* Authentication
* Request timing
* Monitoring

---

# 15. Background Tasks

```python
from fastapi import BackgroundTasks

background_tasks.add_task(
    send_email
)
```

Uses:

* Emails
* Notifications
* Logging

Difference:

Background Tasks:

* Same application
* Lightweight

RabbitMQ:

* Separate workers
* Distributed
* Reliable
